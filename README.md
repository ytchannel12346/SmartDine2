# 悅膳智能餐飲 SmartDine — 智能掃碼點餐與營運管理系統

**SmartDine（悅膳智能餐飲）** 是一套整合**顧客掃碼點餐端**、**登入驗證管理後台**、**廚房顯示系統 (KDS)**、**樓面桌況與呼叫中心**、**會員與優惠券錢包**、**完成上菜後港式電子支付結賬**及**即時雲端資料庫同步**的餐飲系統。

---

## 核心功能亮點

1. **四語即時切換（繁體中文 / 简体中文 / English / 日本語）**
   - 介面控制、菜式名稱與描述、飲食標籤、自訂選項、購物車、AA 分單、電子收據、KDS 工單、樓面狀態與管理後台皆支援即時切換。
2. **顧客掃碼點餐端**
   - 支援堂食桌號（`A01`–`VIP-2`）與 `TAKEAWAY` 外賣自取（自動豁免 10% 加一服務費）、餐桌 QR 碼預覽、呼叫服務員、智能推薦搭配、優惠碼（`WELCOME10`、`LUNCH20`）及 AA 制分單。
3. **會員註冊 / 登入與優惠券錢包**
   - 支援新會員註冊、登入及一鍵示範登入，提供個人優惠券錢包（如 85 折券、滿額立減券、飲品兌換券）與積分累積。
4. **4. 已完成上菜後港式電子支付畫面**
   - 訂單到達「4. 已完成上菜」後自動展開結賬付款畫面，支援 **Octopus 八達通**、**PayMe (HSBC)**、**AlipayHK 支付寶香港**、**WeChat Pay HK 微信支付香港**、**FPS 轉數快** 及 **Apple Pay / Contactless Credit Card**，付款完成後更新狀態並顯示收據。
5. **登入保護管理員後台**
   - 支援帳號密碼與 4 位數 PIN 碼登入：
     - **廚房顯示系統 (KDS)**：秒級計時、超時預警、菜品劃線確認與狀態流轉。
     - **樓面桌況與呼叫中心**：全店桌位狀態總覽、一鍵結賬清枱與服務呼叫處理。
     - **營運數據與菜牌管理**：營收/訂單/客單價/翻枱率統計與菜式庫存、價格及新增菜式管理。
6. **雲端資料庫持久化**
   - 將菜式、桌位、訂單、服務呼叫及會員與優惠券資料同步儲存至雲端資料庫，重新整理或跨裝置開啟亦可保留狀態。
