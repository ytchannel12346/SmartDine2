# SmartDine 悅膳點餐 Android APK 打包專案

此專案已預先綁定網址：
`https://chung.rf.gd/SBA_ICT_Smart_Order_System/phone/index.html`

## 使用步驟
1. 將本資料夾內所有檔案上傳至 GitHub 儲存庫的 `main` 分支。
2. 前往儲存庫的 **Actions** 分頁，等待 **Build Android APK** 執行完成（出現綠色勾號）。
3. 點進該次執行紀錄，在最下方的 **Artifacts** 下載 `SmartDine-debug-apk`（解壓縮即為 `app-debug.apk`）。
